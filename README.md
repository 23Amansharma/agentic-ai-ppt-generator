# 🖼️ Agentic AI PPT Generator

This is a Python-based PowerPoint slide generator built for the **Agentic AI Hackathon 2025** as example project: *"Agentic AI for Intelligent Traffic Management"*. It uses the `python-pptx` library to dynamically create presentation slides with structured content.

---

## 📌 Features

- Generates a professional `.pptx` file with:
  - Title slide
  - Bullet-point slides
- Clean formatting using predefined PowerPoint layouts
- Easily customizable for new content or slide types

---

## 🧠 Why This?

Instead of manually building slides, this tool automates the process and ensures consistency across multiple presentations. It's perfect for teams working on technical projects or hackathons who need quick, clean deliverables.
