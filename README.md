# 🖼️ Agentic AI PPT Generator

A **Python-based PowerPoint presentation generator** designed for the **Agentic AI Hackathon 2025**.

This project demonstrates how presentations can be **automatically generated using code**, making it easier to create structured and professional slides for AI projects.

The generator builds a presentation for the project:

**🚦 Agentic AI for Intelligent Traffic Management**

using the **`python-pptx`** library.

---

# 📌 Features

✅ Automatically generates a **professional `.pptx` presentation**
✅ Includes **title slides and structured bullet slides**
✅ Uses **predefined PowerPoint layouts for clean formatting**
✅ Easily customizable for **different topics or projects**
✅ Saves time by **automating slide creation**

---

# 🧠 Why This Project?

Creating presentations manually can be **time-consuming and repetitive**, especially during hackathons or rapid project development.

This tool helps by:

* Automating slide generation
* Maintaining **consistent formatting**
* Allowing developers to **focus on content rather than design**

It is particularly useful for:

* 🚀 Hackathon teams
* 📊 Technical project presentations
* 🤖 AI or ML demos
* 💻 Developer portfolios

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/agentic-ai-ppt-generator.git
cd agentic-ai-ppt-generator
```

Install dependencies:

```bash
pip install python-pptx
```

---

# ▶️ Usage

Run the Python script to generate the PowerPoint presentation:

```bash
python generate_ppt.py
```

After running the script, the presentation file will be created in the project directory.

---

# 📁 Output

The script generates a PowerPoint file:

```
agentic_ai_traffic_management_presentation.pptx
```

The presentation includes:

* Project Title Slide
* Problem Statement
* Solution Overview
* Key Features
* System Architecture
* Future Improvements
